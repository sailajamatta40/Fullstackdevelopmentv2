# Task Manager — Day 3

A simple command-line Task Manager built with Python as part of the *Day 3 — Git and Collaborative Development* task.

The main purpose of this task is to practice using *Git and GitHub* for version control and collaborative software development.

---

## Objective

The objective of Day 3 is to become comfortable using Git as the basic tool for software development and collaboration.

This project demonstrates:

- Creating and working with a Git repository
- Tracking changes using Git
- Creating meaningful commits
- Working with branches
- Connecting a local repository to a remote repository
- Pushing changes to GitHub
- Pulling changes from a remote repository
- Merging branches
- Using .gitignore
- Understanding Pull Requests
- Understanding code review
- Maintaining a clear project history

---

## Features

- Add a new task
- List all tasks
- Mark a task as completed
- Delete a task
- Exit the application
- Store tasks in memory while the application is running

---

## Technologies Used

- Python 3
- Git
- GitHub
- Command Line / Terminal
