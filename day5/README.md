# Task Manager API

A simple Task Manager REST API built with Python and FastAPI.

## Features

- Create tasks
- List all tasks
- Get a task by ID
- Update a task using PUT
- Delete a task
- Pydantic request validation
- HTTP 404 error handling
- Interactive Swagger API documentation
